# TC-E2E-ALL-FIELDS-TEST-DATA-001

ชุดข้อมูลสำหรับกรอกทดสอบระบบ RTSync แบบต่อเนื่องทุกหน้า โดยใช้ข้อมูลชุดเดียวกันเพื่อดูว่า create, edit, relation และการบันทึกลง Backend ทำงานจริงหรือไม่

## ลำดับการกรอก

ให้กรอกตามลำดับนี้:

```text
1. เพิ่มหมวดหมู่สินค้า
2. เพิ่มหมวดหมู่ supplier
3. เพิ่ม supplier
4. เพิ่ม employee และ role
5. เพิ่มสินค้า แล้วผูก supplier
6. รับสินค้าเข้า stock
7. เพิ่ม customer และ customer type
8. สร้าง quotation / sales
9. สร้าง installation appointment
10. สร้าง service ticket
11. สร้าง fuel claim
12. สร้าง purchase order และเปลี่ยนสถานะ
13. แก้ไขข้อมูลทุก record แล้ว refresh ตรวจซ้ำ
```

| ช่อง | ข้อมูลที่กรอก |

```text

```

## 19. ผลที่ต้องตรวจหลังกรอกครบ

- [ ] ทุก record ถูกบันทึกด้วย API จริง
- [ ] ทุก record ยังอยู่หลัง refresh
- [ ] เปิดหน้าอื่นแล้วข้อมูลสัมพันธ์กันถูกต้อง
- [ ] ไม่มีข้อมูลทดสอบหายไปเป็น mock/localStorage
- [ ] ไม่มี `Failed to fetch`
- [ ] ไม่มี `4xx/5xx` ใน Network
- [ ] สินค้า, supplier, customer และ employee ที่สร้างสามารถถูกเลือกใช้ในหน้าที่เกี่ยวข้องได้
- [ ] ค่าคำนวณ stock, inventory value, quotation total และ payroll total ถูกต้อง
