## วัตถุประสงค์

ตรวจว่า UI ทุกหน้าทำงานครบทุก field, validation, filter, modal, create/update/status workflow และข้อมูลที่บันทึกแล้วถูกส่งไป Backend จริงและยังอยู่หลัง refresh หรือเปิดหน้าใหม่

## ข้อมูลทดสอบ

ใช้ข้อมูลที่ไม่ซ้ำกับของจริง:

```text
Customer: คุณทดสอบ RTSync
Phone: 0899990001
Email: rtsync.test@example.com
Tax ID: 0105559999999
Supplier: บริษัททดสอบ RTSync
Product SKU: TEST-E2E-001
Product name: สินค้าทดสอบ E2E
Employee: ผู้ทดสอบระบบ E2E
```

## Pre-condition และการตรวจระบบ

- [ ] เปิด frontend ได้โดยไม่แสดง `Failed to fetch`
- [ ] เปิด DevTools Network แล้วตั้ง filter เป็น `Fetch/XHR`
- [ ] ตรวจว่า request ไปที่ `http://127.0.0.1:8001/api` ไม่ใช่ localStorage/mock endpoint
- [ ] ตรวจ `VITE_USE_MOCK=false`
- [ ] Backend `/api/health` ตอบ `200` และ `{"status":"ok"}`
- [ ] ล้างค่าค้นหา/ตัวกรองเดิม และใช้ browser ใหม่หรือ incognito session
- [ ] จด request/response ของทุกปุ่มบันทึกไว้ตรวจซ้ำหลัง refresh
